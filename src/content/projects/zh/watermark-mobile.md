该项目将深度学习水印与移动端图像处理相结合，用于支持图像版权保护与身份认证。

项目主要体现以下工程能力：

- 软件架构与移动端实现；
- 神经水印模型集成；
- 图像处理工作流设计；
- 使用 Git 开展团队协作。
