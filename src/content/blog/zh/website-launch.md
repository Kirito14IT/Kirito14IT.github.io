本网站被设计为公开学术主页，而不是 PDF 简历的简单在线副本。

第一版重点包括：

- 以科研内容为核心的简洁首页；
- 不包含私人住址、电话号码、具体分数或绩点的网页版简历；
- 可逐步扩展为可复现研究笔记的项目页面；
- 用于技术写作和论文阅读记录的 Markdown 博客；
- 展示公开开源活动的 GitHub 贡献图。

后续更新将持续补充 arXiv 链接、项目图片、精选博客文章，以及适合公开展示的稳定代码仓库链接。
