SFMambaNet: Frequency-Aware Mamba for Two-View Correspondence Learning

Correct matches between two photos shift together; wrong ones jump against their neighbours. SFMambaNet scans the matches cluster by cluster, where that difference becomes one of frequency, and filters its Mamba scans with learnable frequency-domain gates.

01 · Insight

Frequency needs an order.

Correspondences form a set, and a set has no spectrum until it is read in some order. Read at random, where each match lands in the second image is noise for inliers and outliers alike. Read cluster by cluster, the inliers move in smooth, low-frequency steps while the outliers stay erratic.

02 · Method

Prune twice, verify once.

Two pruning blocks each keep the more reliable half of the matches. A verification block then fits the essential matrix with a weighted eight-point solver and re-checks all N matches, which recovers inliers dropped along the way. Frequency enters every pruning block twice: locally in LSGA, globally in SIGM.

Click a block · strands are matches: green inliers, red outliers

Local · LSGA

Local Spectral-Geometric Attention

Relative neighbour offsets ΔC are lifted into Fourier features with a fixed Gaussian projection B, so a small difference in motion becomes a large difference in the encoding. A local attention weighs neighbours by feature similarity and geometric consistency, and DiffPool groups the matches into clusters whose order Π defines the scan.

Efreq = [ sin(2πBΔC) ; cos(2πBΔC) ]  ·  Π = Order(DiffPool(FM))  ·  FG = Π−1(BiMamba(Π FM))

Global · SIGM

Spectral-Integrated Global Mamba

A forward Mamba scan runs along the cluster order. Its output is gated in the frequency domain, flipped, scanned backwards and gated again, so the second scan reads filtered features. The complex-valued gates learn amplitude and phase per channel and frequency, and leave Mamba's state transition untouched.

FSfwd = IFFT( FFT(Mamba(Π FGL)) ⊙ W1 )  →  Flip  →  Mamba  →  ⊙ W2  →  LN( · + · + · )

O(DN log N) per FFT O(DN) per scan 12 spectral gates · < 5% of the parameters 2.01M parameters · 5.01 GFLOPs

03 · Results

More accurate, and lighter.

Without RANSAC, SFMambaNet is the most accurate pruner on every split of relative pose estimation, with SIFT and with SuperPoint. It also gives the best precision and F-score in outlier removal and the best homography accuracy, with slightly fewer parameters and FLOPs than MatchMamba.

04 · Analysis

Frequency, not capacity.

Controlled experiments ask why it works. Point-wise layers of exactly the gates' size lose most of the gain, a parameter-free low-pass filter keeps more of it, and the learned gates, left alone, become low-pass. Every number below is a five-seed mean.

Components

What each module adds

The baseline swaps LSGA and SIGM for identities. From known to unseen scenes the gain of LSGA shrinks while that of SIGM holds, so global frequency gating is what carries the model to new scenes.

On unseen YFCC100M (mAP@5°), LSGA adds 8.84 points and SIGM another 8.93.

Gate controls

Filtering beats capacity

Same network, four gates. Point-wise MLPs with exactly the gates' parameter count recover little; a fixed low-pass filter with no parameters does better; learning the response adds the rest.

Over identity gates on unseen YFCC100M: MLP +0.68 · low-pass +1.55 · learned +3.16

Encoding control

Sinusoids, not dimensions

Inside an unchanged attention, a linear lift to the same 128 dimensions gains almost nothing over raw coordinates, while Fourier features roughly triple the gain that raw coordinates bring over no explicit geometry.

Over no explicit geometry on unseen YFCC100M: raw +0.80 · linear lift +0.89 · Fourier +2.81

Inside the trained gate

The learned gate is low-pass

Nothing in training asks for a frequency response, yet the isolated first-stage gate keeps most of the low band and little of the high band. The network relies on that shape, not on energy.

Gating also tames the scan order. Mamba reads a sequence, but matches form a set. Shuffle all inputs twenty times and the pose accuracy of the gated model moves by only 0.08 points on YFCC100M and 0.06 on SUN3D, while the matches it keeps overlap by at least 98.5%. Along the cluster order, a shuffle only reorders matches inside a cluster, a high-frequency change that the gates remove.

05 · Code

Run it yourself.

The repository holds the data-preparation, training and evaluation code. Dump YFCC100M or SUN3D correspondences with the OANet protocol, then evaluate a checkpoint with RANSAC turned off.

1 · environment
git clone https://github.com/Kirito14IT/SFMambaNet.git
cd SFMambaNet
conda create -n sfmambanet python=3.10 -y
conda activate sfmambanet
pip install torch==2.1.1 --index-url https://download.pytorch.org/whl/cu118
pip install opencv-contrib-python==4.7.0.72 mamba-ssm==1.2.0.post1
pip install h5py matplotlib numpy six tensorboard thop tqdm
2 · YFCC100M correspondences
# raw data from OANet's Google Drive (see the README):
# raw_data/yfcc100m and raw_data/pairs
mkdir -p data_dump
cd dump_match
python extract_feature.py --input_path ../raw_data/yfcc100m
python yfcc.py --raw_data_path ../raw_data/ --dump_dir ../data_dump/
cd ..
3 · evaluate without RANSAC
cd core
python main.py --run_mode=test \
  --data_te=../data_dump/yfcc-sift-2000-test.hdf5 \
  --model_path=/path/to/checkpoint_directory \
  --res_path=../outputs/yfcc_sift/test \
  --log_base=../outputs/yfcc_sift \
  --use_ransac=False --gpu_id=0

Availability. The public repository is a code snapshot: data preparation, training and evaluation are included, but the model is not yet fully synchronized with the revised manuscript, and no pretrained checkpoint is released. The numbers on this page are the ones reported in the paper.
