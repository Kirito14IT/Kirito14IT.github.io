This website is designed as a public academic homepage rather than a direct PDF mirror.

The first version focuses on:

- a clean research-first home page;
- a web CV without private address, phone number, exact scores, or grade points;
- project pages that can grow into reproducible research notes;
- a Markdown blog for technical writing and reading logs;
- a GitHub contribution graph that reflects public open-source activity.

Future updates should add arXiv links, project images, selected blog posts, and stable repository links when the work is ready to be public.
